### Severity and release decision

1. **P0 mitigated locally, still a backend blocker:** Storage deletion was possible before proving reference safety. UI/service deletion is now disabled. Review storage policies and create a verified usage/recovery workflow before enabling deletion. No SQL was run.
2. **P1 implemented, live verification needed:** Users now reads authorized profiles; confirm the profiles RLS migration and actual admin/super-admin/editor visibility in staging before release.
3. **P1 implemented, live verification needed:** Content Health and legacy Home/About navigation moved. Verify live scan, homepage slide edit/reopen and Calendar daily routing in staging.
4. **P1/P2 outstanding:** The route sweep cannot prove live CRUD, bilingual search, six-state publication, CMS-to-public reflection, private media access or all error states. Run the A–P matrix with authorized staging accounts and representative records. Six-state Faith Challenges schema deployment is explicitly unverified in project status.
5. **P2 outstanding:** `cms-admin-smoke.mjs` uses an older mock table set and fails on `mezmur_data_import`. Repair that fixture around current service contracts before using it as a release gate. The repository-wide ESLint run reports 362 errors and 28 warnings across existing/unrelated files; targeted lint for the changed CMS files passes.
