# Faith Challenges: full content integration (2026-11-13)

Branch `feat/faith-challenge-full-integration`. There is no `AGENTS.md` in this repository.

## What was traced, and what was wrong

Content reaches players through three layers: built-in banks (`approvedContent.ts`, `bibleTimeline.ts`, `bibleAdventureStories.ts`, `imageCatalog.ts`), the validated generated bank (`src/lib/play/generated/*.json`, built by `scripts/play/build-published-bank.ts`), and optional published rows (`play_content_items`). The public role sees **no** rows in `play_content_items`, so everything playable today is bundled in the app; nothing here depends on, or writes to, the database.

## Review status

Generated items are machine-validated, not human-reviewed, and their Amharic text is unreviewed (`verifiedLocales: ['en']`), so they show the existing English fallback. Every game that includes them shows a calm note saying so and that they are not an official statement of the Church. Built-in items keep their existing metadata. No content, translation or citation was created to reach a count. There is no content-reporting feature in the app, so none was added.
